# NEV Policy Tables — 新能源汽车政策时间线数据

中国 / 欧盟 / 美国 新能源汽车及碳关税政策时间线数据，中英双语。

## 数据内容

| 地区 | 时间跨度 | 政策条数 | JSON |
|------|---------|---------|------|
| 🇨🇳 中国 | 1986–2026 | 71条 | `China_NEV_policy_table_CN.json` / `_EN.json` |
| 🇪🇺 欧盟 | 2009–2026 | 42条 | `EU_NEV_policy_table_CN.json` / `_EN.json` |
| 🇺🇸 美国 | 2009–2026 | 61条 | `US_NEV_policy_table_CN.json` / `_EN.json` |

## 数据字段

每条政策包含：
- `date` — 发布日期（或年份/月份）
- `policy_name` — 政策名称   
- `issuing_body` — 发布机构
- `content` — 核心内容摘要
- `source` — 来源链接/出处

## 使用场景

- 学术研究中的政策对比分析
- 企业全球化战略的宏观环境调研
- 碳关税/新能源汽车产业趋势分析
