# NEV Policy Tables - 新能源汽车政策时间线数据

中国 / 欧盟 / 美国 新能源汽车及碳关税政策时间线数据，中英双语。

## 数据内容

| 地区 | 时间跨度 | 政策条数 | 文件 |
|------|---------|---------|------|
| 中国 | 2001-2026 | 45条 | `data/China_NEV_policy_table_{CN,EN}.json` |
| 欧盟 | 2009-2026 | 43条（含CBAM） | `data/EU_NEV_policy_table_{CN,EN}.json` |
| 美国 | 2008-2026 | 37条（含IRA） | `data/US_NEV_policy_table_{CN,EN}.json` |

## 数据格式

每条政策包含：发布日期、政策名称、发布机构、核心内容、来源链接。
